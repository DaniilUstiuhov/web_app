# MultiPlay - Multiplication Table Game

Academic project for the course **Veebirakendused** (Web Applications).

**Live demo:** https://multiplay-danja.web.app

## About
<img width="517" height="489" alt="image" src="https://github.com/user-attachments/assets/59f1fbfa-83d2-40be-ab30-99d353e10ad0" />


A browser-based multiplication table training game. Choose difficulty, answer as many questions as you can in 60 seconds, and compare your score on the leaderboard.

Supports Estonian, Russian, and English. Light and dark theme.

## Tech stack

- React 18 + TypeScript + Vite
- Firebase (Firestore, Hosting)
